## Screening and stopping

Screen the fixed prefix in order. Reject if the opening report or available
actor source gives the fault path or repair, if the issue is a policy or
feature choice, if there is no deterministic WSL reproduction, or if no
independent consequential follow-up invariant could survive the public
check. A later public PR can help assess whether a natural case is already
contaminated; it is not a reason to redact the opening issue. A promising
lead still needs a pinned pre-report source revision, license, dependencies,
baseline and narrow-wrong calibration, two complete repairs, a distinct
public follow-up and an independent protected oracle, all provider-free.

Stop after the selected prefix even if no row qualifies. Before any paid
producer, separately freeze the target population, paired S/A analysis,
