## Delivered behaviour

`tools/worker_tasks.py` and the installed `/worker-task` command expose the
existing durable B0 API without requiring an operator to write Python. The
CLI admits a task from a bounded JSON request, inspects its journal and budget,
executes B0, and exposes cancellation, blocked-task resume, linked continuation,
rubric review, uncertainty reconciliation, partial closure and N3 shadow
selection. Only `run` can dispatch a provider call. Admission rejects unknown
fields, including campaign dispatch specifications, and does not spend.

The CLI owns a process lock for the entire run. A second driver cannot treat a
live invocation as a crashed operation. Durable cancellation from another
process is relayed to the adapter that owns the worker; Ctrl-C requests the
same cancellation. Receipt evidence, stopped-writer proof and settled charges
remain necessary. Status readers use the root lock because Windows can reject
an atomic file replacement while another thread has the old file open.

`preflight.py --status` now reports durable roots and rollback readiness.
The new `WORKER-TASKS.md` guide, command, core instructions, routing reference,
lifecycle, selector guide, self-learning document and both README sources
describe one task owner, exact B0 behaviour, N7's negative decision and the
host limits. The guide contains the current capability matrix.

No frozen campaign or shared `task_executor.py` source was changed. The N7
grader and dependency-seal findings remain blockers to future qualification;
they were not hidden by changing the old experiment after its results.

## Supported scope and remaining limits

The installed CLI and parser were exercised with fake workers. A live Claude
session interpreting the new slash-command prompt was not run. The general
adapter can request restricted tools and actor-scoped Graft but does not prove
filesystem isolation, descendant termination or served reasoning effort.
Corpus-specific WSL evaluation wrappers do not establish those guarantees for
an arbitrary consumer repository. Managed children remain rejected by the
general live adapter; arbitrary Agent-tool launches are prompt-governed and
outside the durable root budget. These are explicit capability limits, not
features qualified by a passing fake test.

Graft MCP was used for source discovery. Its scoped tools refreshed the
structural graph and returned the relevant APIs. MCP freshness timed out;
the standalone checker eventually reported retained patch files and partial
semantic coverage, including stale summaries for the pinned executor. No
unchanged paid semantic retry or new Claude provider call was made in N8.
