## Review and execution contract

One normal B0 Sonnet-low producer gets the original issue. Only a settled,
writer-stopped, identity-valid public success with the frozen risk can create
single-use S/A twins. Their accepted source bytes are identical. The host
generates an identical `REVIEW.md` from the public risk and bounded producer
edit summary in each twin; the goal hash is saved. Both roots are admitted
against that review goal. S gets one direct Sonnet-low worker call. A's public
assessment names that exact goal file and includes the risk citation. A
then gets one bounded Controller investigation. The workflow returns with a
ready root, exits the private evaluation mount view, and launches one
Sonnet-low worker only if the Controller handoff has a source-cited concrete
review action. The same accepted public check verifies both. The hidden
oracle remains unopened until both arms settle and qualify.

The mechanism tests now cover equal review goals, an assessor issue that
matches the frozen task goal, tampered twin rejection, and deferred worker
dispatch. A provider-free Q3 Graft build succeeded outside the hidden mount
view after K01's nested build failed inside it. This supports the boundary
change but does not guarantee a future live dispatch.

## Cost, stopping and interpretation

The proposed manifest ceiling is USD 5 per root, a USD 0.5 A public
assessment, one Controller invocation with its existing USD 4 cap, and
USD 20 overall. Estimated reported API-equivalent spend is USD 0.2–6;
actual subscription billing is uncertain. The operator's approval of all
planned tests still requires a dated notice bound to the exact K02 manifest
before each paid mode. The run stops on any source drift, bad citation,
public failure, open charge, invalid identity, failed Controller handoff or
preflight failure. Neither the producer nor a settled arm is replayed.

Score protected quality, critical duplicate-debit errors, false completion
claims, cost and elapsed time separately. A public pass is not quality
uplift. A single A-over-S gain would be provisional; reserved cases, power
planning and independent review remain necessary before changing B0.
