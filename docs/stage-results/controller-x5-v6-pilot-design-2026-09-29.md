## Comparison and order

Each of the six frozen public actor packages is copied unchanged into three
fresh root-owned WSL projects. B runs the frozen B0 worker policy. S uses the
qualified public worker assessment and selected worker cell without a
Controller. A uses that same worker policy plus automatic rigour routing. The
S and A worker campaign prompt is identical. B carries its historical prompt.
The public issue, source, trace, check and initial report bytes are identical
within a task across arms. The only frontier role-profile trial is the A arm
of X5-MIGRATE; it is an explicit experimental request, while other A arms
retain the standard profile. It does not qualify frontier selection by itself.

The 18 episodes are ordered by task with rotating B/S/A order, so each arm
appears first, second and third across tasks. Each root has an USD 8 local
cap, making the pilot ceiling USD 144. S and A public assessments are capped
at USD 0.50 within their task roots; B has no public assessment call. The
Controller allowance and worker follow-on share the same N1 root budget.
The pilot stops after an unqualified host, an unresolved charge, a failed
required admission, an unexpected A route or an interrupted episode. A task
can fail acceptance without stopping the pilot if accounting and admission
remain qualified; that failure is an outcome to measure. A started episode
cannot be replayed automatically. Later episodes require matching prior N1
root cost and settled state, not merely a result label.

## Independent outcome measurement

The four X5 cases use their protected weighted behavioural checks and an
isolated grader. The two unchanged X3 controls use their existing protected
oracle, task rubric and isolated execution boundary on the worker's actual
files. In both paths, an actor cannot read the oracle. M/E/D/N/H quality uses
weights 40/25/15/10/10, with zero quality for a critical violation and an
explicit false-success flag. Verified probes, causal diagnosis and truthful
next steps can earn partial credit. A route label or public-check pass alone
cannot earn full acceptance.

Each episode receipt records provider-reported task spend, elapsed time,
public assessment charge, worker attempts, requested cell and effort, actual
served model, unsupported served-effort telemetry as unknown, Controller
admission, role-budget location, protected score and unresolved holds. The
analysis reports arm and task-family totals, p95 elapsed time, component
scores, critical errors, false successes, matched A-S and S-B task deltas,
frontier exercise and the real clarification action. The six-task pilot is
development evidence; X6 reserved cases remain unseen and no default switch
is authorised by a favourable pilot.
