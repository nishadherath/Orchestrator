# Q4U U2: public-check coverage hypothesis

Date: 2026-09-26 UTC. Status: **provider-free rule freeze, not a routing
qualification**. B0 remains the shipping default. No provider call or paid
episode was replayed.

`tools/worker_q4u_coverage.py` is an isolated offline assessor and policy
table. It takes caller-supplied public issue and check text; it does not read
an actor tree, hidden grader or model response. Each criterion has an exact
issue line citation and zero or more public-check line citations, including
SHA-256 of each cited file. `direct` requires a check citation; `partial`
requires a check citation and a stated missing condition; `unknown` records
uncertainty. Unknown dominates the aggregate, then partial, then direct.
The validator rejects paths with hidden/oracle/reference/result segments in the supplied
inventory and rejects stale citations. A digest prevents a validated
assessment from being changed before the offline policy reads it. A line
citation proves the source of an assessment, **not** that the check semantically
covers the requirement.
Before any paid screen, a reviewer must assess that mapping using public
material. The policy uses only structured labels, never issue keywords,
task IDs or hidden outcomes. An assessment can be supplied by the normal
assessment turn without a separate provider call, but its overhead has not
been measured and must be counted in a live comparison.

The versioned rules are:

| Policy | Initial cell | After a low result | Availability and cost |
| --- | --- | --- | --- |
| B0 | Sonnet-low | Existing bounded repair tail | Stop if the cell or enforced ceiling is unavailable. |
| Cross-component medium | Sonnet-medium only for an assessed cross-component public contract; otherwise Sonnet-low | Existing bounded repair tail | Abstain to Sonnet-low if medium is unavailable. |
| Coverage repair | Sonnet-low | A qualified low failure may request one Sonnet-medium step only for an implementation task with an explicit change requirement and `partial` coverage. An accepted low result stops; blocked evidence stops for review. `direct`, `unknown` and no-edit tasks retain B0 repair. | Abstain to B0 repair when medium is unavailable; stop on unenforced or unfunded ceiling. |

The table emits one action at a time and `dispatch: false`. It reserves the
full per-call local ceiling for every selected action. A low-first medium
continuation would pay for the first low call **plus** any medium call. It
cannot borrow the independent, pristine-source medium outcome from Q4T as
its own result, latency or cost. The real executor's remaining repair tail
and total episode budget must be frozen separately for U3.

The S05 public issue explicitly requires bounded retained memory; its public
check makes five peeks and checks behaviour but has no memory bound. Exact
public citations classify that criterion as `partial`, so the proposed table
would start low and *could* request medium after a qualified no-change or
failed-verification result. Q4T's two low roots made no source edit, and its
separate medium root passed hidden acceptance. These observations motivate a
prospective continuation test but **do not measure** its outcome. S01, S02,
S04 and T07 showed no benefit from medium when selected by the
cross-component rule; this argues against promoting that rule, not for an
estimated gain from the new one. The already-correct/no-edit N5 control
must remain outside changed-output enforcement.

`test/harness/worker_q4u_coverage_tests.py` passed **8/8** provider-free
checks. They cover citation tampering, hidden-path rejection, all three
rules, stops, cost ceilings, unavailable medium, assessment tampering,
no-edit control, two paraphrases with identical routing, and the exact S05
public issue/check.
