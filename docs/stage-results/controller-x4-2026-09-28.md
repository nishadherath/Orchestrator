## Boundary for X5

Only one explicit-`on` standard-profile Framer-to-worker live path is
qualified. Other roles and the frontier profile have offline capability
checks but lack live Graft/use and suitability evidence. The X5 pilot must
exercise a frontier role, count actual automatic Controller admissions and
grade worker results independently. A public check pass, fake trigger or role
call count cannot establish uplift. The reserved X6 comparison remains
exploratory and cannot alone authorise automatic default promotion.
