Date: 2026-09-26 UTC. This notice freezes a proposed screen; it makes no
provider call. The later live-driver stage must recheck the date and all source
and runtime hashes before dispatch.

The prospective screen has six task families and three fresh arms per family:
two Sonnet-low repetitions and one Sonnet-medium arm. Each episode has a USD 4
local allocation and the common conditional Sonnet-low / Opus-high repair
tail. The maximum is **18 episodes, 54 provider calls and USD 72 in local
allocations**. These are local admission limits, not a guarantee against an
in-flight provider overrun. A started invocation is never automatically
replayed. The user's standing approval for paid calls covers this bound.

Projected Claude API-equivalent usage is **USD 5–40** and elapsed time is
**2–8 hours**. This planning interval uses the prior S4's three calls at USD
0.581133201, the C1 Q4T canary at USD 0.0881134, a wide allowance for
longer tasks, conditional Opus calls, five report-format attempts, and cache
variation. It is not a prediction of the Claude Code subscription invoice;
that impact is unknown. The live ledger will record provider-reported cost
for every settled call.
