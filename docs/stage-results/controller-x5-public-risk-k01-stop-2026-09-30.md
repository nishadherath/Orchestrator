## Diagnosis and next design boundary

The worker preflight failure occurred while `controller_workflow.execute`
ran Controller and worker dispatch inside `hidden_evaluation_tree`. That
context hides evaluation material in a private mount namespace. The nested
Q3 Graft build attempted to unmount `/mnt/c` and failed as busy. The
causal link to the enclosing mount namespace is an inference; the recorded
facts are the nested build failure before `_invoke` and the unresolved hold
that was later reconciled. A subsequent pilot must separate the Controller
investigation from worker launch, exiting the hidden evaluation view before
starting the worker, while keeping its frozen decision and ledger.

The Controller was asked to assess the original rotation issue after that
issue had already passed publicly. It cited the shared-key feed but treated
the original acceptance problem as the active task, leading to a generic
handoff. A post-success review needs a distinct, frozen review goal containing
the public risk, next check and accepted edit summary. The S and A worker
goals must be identical; the A Controller public packet must use that same
review goal as its issue source. A fresh case and new roots are required.

Negative C01 and M01 packets remain provider-free rubric controls. A single
fresh positive pair, if achieved later, would be provisional; production
routing still requires reserved cases, power planning and independent review.
